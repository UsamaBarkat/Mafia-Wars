# tasks-2b.md — Mafia Wars · Phase 2 Slice 2b Task Breakdown

Backend (unchanged): **Firebase, Spark/free, no Cloud Functions; RTDB; Anonymous Auth.** The moderator's device is the **resolver** (reads secret inputs, writes public outcomes), exactly as it dealt roles in 2a. 2b picks up after the 2a deal + reveal. Reuse the 2a data layer, subscriptions, presence, lifecycle, and reconnect wherever possible.

Convention per task: **Goal**, **Files**, **Satisfies**, **Done when**, **Depends on**.

> **Numbering** continues 2b's own 1–14. Security Rules land **before** any UI that relies on them (task 2), and the pure resolver logic lands **before** the UI that uses it (task 3), same discipline as 2a.

## How to test 2b end-to-end (multiple browser windows)

You need the **moderator + several players**, each a **separate browser session** so they get **different anonymous `uid`s** — use different browsers or Chrome profiles (separate incognito windows of the same browser share one uid). Run against the **Firebase Emulator Suite** (`npx firebase-tools emulators:start` + `npm run dev`), and keep the **Emulator DB tab** open to inspect `game`, `rounds/{n}`, and `players/{uid}/alive`.

1. **Set up a game (2a):** moderator CREATE GAME; e.g. 5 players join; moderator sets **2 Mafia / 1 Detective / 1 Doctor / 1 Civilian** (6 total needs 6 players — size to your window count); START; everyone views their role.
2. **Begin Night 1:** moderator taps Begin Night 1 → players enter the night. Confirm each Mafia sees their teammate; the Detective/Doctor see pickers; the Civilian waits. In the DB, confirm `nightActions/{uid}` is written and that one player **cannot** read another's (repeat the task‑7‑style console read test).
3. **Resolve night:** both Mafia target the same player; Doctor protects someone else; Detective investigates a Mafia. Moderator **End Night** → everyone sees "X was eliminated" (no role shown); the Detective privately sees "… is Mafia". Try again with the **Doctor protecting the Mafia's target** → "no one died".
4. **Day 1:** survivors vote publicly; watch the tally update live across windows; change a vote; confirm the eliminated player has no vote controls. Moderator **End Day** → most‑voted is eliminated (try a **tie / Skip** → no elimination).
5. **Spectate:** an eliminated player keeps watching phases, tally, and outcomes but has no controls and can't read roles.
6. **Play to a win:** continue rounds until all Mafia are out (**Town wins**) or Mafia reach parity (**Mafia win**) → game‑over screen reveals **all** roles (the only reveal).
7. **Resilience:** **refresh** a player mid‑night and mid‑day → they return to the right view; refresh the moderator → back to the console. **Close the moderator tab** mid‑game → players fall to the "game ended" screen (2a abandon handling).
